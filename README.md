# sevkit-landing

Sevkit'in tanıtım sayfası ve gezilebilir demosu. GitHub Pages ile yayınlanır.

- `index.html` — tanıtım sayfası (tek dosya, kütüphane yok, yalnız Google Fonts).
- `demo/sevkit-demo.html` — Sevkit arayüzünün örnek verilerle çalışan demosu.
  Giriş: `demo` / `demo`. Sunucu gerekmez, veriler tarayıcıda kalır, hiçbir şey kaydedilmez.

Ürünün kendisi ayrı bir depoda geliştiriliyor. Demo dosyası oradaki `npm run demo`
komutuyla üretilir ve buraya kopyalanır.
